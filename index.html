Acceso desde Cualquier Celular (GitHub Pages)

Ten tu aplicación disponible 24/7 en internet gratis.

Pasos para activar en GitHub Pages:

  1. Crea un repositorio en GitHub llamado takirin-contratos.
  2. Sube todos los archivos del proyecto a la rama main.
  3. Ve a Settings → Pages y selecciona la rama main / root.
  4. Abre el enlace en tu celular y ¡los contratos que crees en el celular se sincronizarán con tu computadora automáticamente!
